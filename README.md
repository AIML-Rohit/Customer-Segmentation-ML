# Customer-Segmentation-ML
Customer Segmentation using Python, PCA, K-Means, and clustering to understand customer spending and purchasing behavior.

# Customer Segmentation Using Machine Learning

## About the Project

This project focuses on understanding customer behavior using machine learning. It groups customers based on their income, spending habits, and shopping activities.

The goal is to find different types of customers and understand their purchasing patterns.

## Dataset

* Customer information
* Income and spending details
* Shopping and purchase history
* Customer education and family information

The dataset contains 2,240 rows and 22 columns before preprocessing.

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* Jupyter Notebook

## Project Steps

1. **Data Cleaning:** Checked missing values and filled missing income values using the median.
2. **Data Preprocessing:** Prepared the data and removed unnecessary columns.
3. **Feature Engineering:** Created new features such as age, total spending, and customer tenure.
4. **Data Visualization:** Used charts to understand customer data and patterns.
5. **Dimensionality Reduction:** Used PCA to reduce the number of features.
6. **Clustering:** Applied clustering methods to group customers based on their behavior.

## Goal

The main goal is to understand different customer groups and their spending patterns. This can help businesses better understand their customers and plan suitable marketing strategies.

## How to Run

1. Clone this repository.
2. Install the required Python libraries.
3. Open the Jupyter Notebook.
4. Run the notebook cells step by step.
